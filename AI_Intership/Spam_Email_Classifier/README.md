# MailGuard AI - Spam Email Classifier

## Project Description

MailGuard AI is a machine learning based Spam Email Classifier.
It automatically identifies emails as Spam or Normal (Ham).

## Features

- Spam email detection
- Normal email detection
- TF-IDF text feature extraction
- Multinomial Naive Bayes machine learning model
- Accuracy calculation
- Professional graphical dashboard
- Email detection statistics
- Recent detection history

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Tkinter
- Machine Learning
- TF-IDF
- Multinomial Naive Bayes

## Project Files

- `app.py` - Main GUI application
- `main.py` - Machine learning program
- `dataset.csv` - Email training dataset
- `screenshots/` - Project screenshots
