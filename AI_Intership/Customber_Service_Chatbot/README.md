# Customer Service AI Chatbot

## Project Description

Customer Service AI Chatbot is a Python-based chatbot that provides
automatic responses to common customer service questions.

## Features

- Customer support chatbot
- Order information
- Delivery information
- Return and refund information
- Payment information
- Contact support
- Professional graphical interface
- Clear chat option
- Enter key support

## Technologies Used

- Python
- Tkinter
- Artificial Intelligence
- Natural Language Processing concepts

## How to Run

Run the following command:

```bash
py chatbot.py
